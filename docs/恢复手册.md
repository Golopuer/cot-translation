# cot-translate 恢复手册

> DSH 进程重启后按此手册快速恢复「思维链人话翻译」功能。
> 动态插件是进程内临时的，重启后插件定义和后台服务会丢，但磁盘资产不丢。

## 一、磁盘资产（重启不丢）

| 资产 | 路径 |
|---|---|
| 模型权重 | `server/models/Qwen3.5-0.8B`（或 `QWEN_LOCAL_MODEL_DIR` 指向的目录） |
| 翻译服务 | `server/serve.py`（本仓库） |
| 翻译网页 | `server/index.html`（本仓库） |
| 插件源码 | `plugin/host.js` + `plugin/client.js`（本仓库） |
| 译文历史 | 默认 `./cache/cot-translate/history.jsonl`（以 DSH 会话工作区为基准） |

## 二、恢复步骤

### 第 1 步：启动本地翻译服务（后台）

```
python server/serve.py
```

验证：`http://127.0.0.1:7860/health` 应返回 `{"ok": true, "device": "cuda", ...}`

### 第 2 步：重建插件

本插件是 DSH「动态 Cordis 插件」。在 DSH 对话中：

1. 把 `plugin/host.js` 的内容提交为 `cordis_define` 的 `code.host`；
2. 把 `plugin/client.js` 的内容提交为 `code.client`；
3. `cordis_run`（mode:"run"）并请用户批准。

> 动态插件是进程内临时的，DSH 重启后需重新激活。

## 三、关键参数速查

| 参数 | 值 | 位置 |
|---|---|---|
| 分块阈值 | 句末标点+800 字 或 1500 字强制 | `plugin/host.js` `flushSegment` |
| 节流间隔 | 300ms | `plugin/host.js` `drain` 里 `ctx.timeout` |
| 语言判断 | ascii>20 且 ascii>cjk*3 | `plugin/host.js` `isMostlyEnglish` |
| 翻译端口 | 127.0.0.1:7860 | `plugin/host.js` + `server/serve.py` |
| 历史存储目录 | `./cache/cot-translate` | `plugin/host.js` `HISTORY_DIR` |

## 四、翻译提示词位置

`server/serve.py` 的 `TRANSLATE_SYSTEM` 变量，默认「人话版」；
提示词优化思路与 A/B 实测见 `docs/技术报告.md`。
